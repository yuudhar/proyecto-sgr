{% comment %} Un mantenedor que además se puede eliminar de verdad (crud.deletable) muestra dos acciones distintas: «Archivar» (el registro se oculta y se puede restaurar) y «Eliminar» (se borra de la base). Si el mantenedor solo se archiva, esa única acción se llama «Eliminar», como siempre. {% endcomment %}{% if kind == "archive" and crud.deletable %} Archivar{% else %} Eliminar{% endif %}
